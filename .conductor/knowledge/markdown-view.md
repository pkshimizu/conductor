# 方針「Markdown 表示」

管理画面（`web/`）で Markdown の文章を見せるときの決まり。

## 部品

- Markdown の表示には、共通の部品 `web/src/MarkdownView.tsx` の `MarkdownView` を使う。画面ごとに別の描き方を作らない。
- 描画には `react-markdown` と `remark-gfm`（表・取り消し線・タスクリスト・自動リンク）を使う。どちらも画面のビルドに入るだけなので、`react` と同じく `devDependencies` に版を固定して入れる。

## 安全

- 文中の生の HTML は描画しない（`rehype-raw` などは入れない）。HTML のタグは文字としてそのまま見せる。
- リンクは `react-markdown` の既定の URL の検査（`javascript:` などを落とす）をそのまま使う。外へのリンクは `target="_blank" rel="noopener noreferrer"` で開く。
- 画像は読み込まない。`![alt](url)` は alt の文字（alt が空なら URL）を斜体で見せる。外部への通信が起きないようにするため。
- タスクリストのチェックボックスは `<input>` にしない。`☐`／`☑` の文字で見せる。見るだけの画面に入力欄を作らないため。

## 見た目

- 色・枠・背景はテーマの CSS 変数（`--border`・`--subtle`・`--muted` など）を使い、明るいテーマと暗いテーマの両方で読めるようにする。
- コード（インライン・ブロック）は既存の等幅フォント `MONO` を使う。コードブロックは横に長いとき横スクロールにする。
- 見出しは画面の見出しより目立たないよう、h1 でも 18px 程度に抑える。

## 原文の切り替え

- 書かれた文字そのものを確かめたいことがあるので、`MarkdownView` を使う箇所には「整形」「原文」を切り替えるボタンを付ける（既定は「整形」）。原文は今までどおり `<pre>` で見せる。
