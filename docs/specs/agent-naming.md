# 「～役」の表示を「～エージェント」にする

## 要件

> `～役`と表示している箇所を、`～エージェント`と表示したい

## 今の動き

- 人に見せる文章（GitHub のコメント・PR の本文、Discord の書き込み、管理画面、ログ）で、各役を「テスト役」「実装役」「レビュー役」「仕様化役」「分解役」、conductor 自身を「指揮役」と書いている。
- 管理画面には「役」だけを使った文言もある（「役ごとの追加許可」「役の許可」「役ごとの指示ファイル」「役」の見出しなど）。

## 仕様

### 1. 呼び名を変える

人に見せる文章の呼び名を次のように変える（方針「エージェントの呼び名」により判断）。

| 今         | 変えた後             |
| ---------- | -------------------- |
| テスト役   | テストエージェント   |
| 実装役     | 実装エージェント     |
| レビュー役 | レビューエージェント |
| 仕様化役   | 仕様化エージェント   |
| 分解役     | 分解エージェント     |
| 指揮役     | 指揮エージェント     |
| 役（単独） | エージェント         |

「CI」「CI の確認」「マージ」は役ではないので変えない。

### 2. 変える場所

#### 管理画面（`web/src/i18n.ts` の `ja`）

| キー                | 変えた後                                                                              |
| ------------------- | ------------------------------------------------------------------------------------- |
| `restartBody`       | 動作中のエージェントはいったん止まります。設定の変更は再起動のあとに反映されます。    |
| `stopBody`          | GitHub の確認とエージェントの実行を止めます。再開するには「再起動」を押してください。 |
| `someRole`          | エージェント                                                                          |
| `concurrency`       | レビューエージェントを同時に動かす数                                                  |
| `autoDesc`          | レビューエージェントが承認したらすぐマージ                                            |
| `language2`         | エージェントが書く文章の言語                                                          |
| `secProtected`      | 実装エージェントに変えさせないファイル                                                |
| `protectedHelp`     | glob で指定します。実装エージェントはここに当てはまるファイルを変更できません。       |
| `secPerms`          | エージェントごとの追加許可                                                            |
| `permsHelp`         | エージェントごとに、追加で許可する操作を指定します（例: Bash(npm run lint)）          |
| `secPrompts`        | エージェントごとの指示ファイル                                                        |
| `role`              | エージェント                                                                          |
| `tabPerms`          | エージェントの許可                                                                    |
| `roles.tester` など | 1. の表のとおり（`ci`・`merge` は変えない）                                           |

英語（`en`）は変えない（方針「エージェントの呼び名」により判断）。

#### 中断の文（`src/loop.ts`）

- `ROLE_LABELS` を 1. の表のとおりにする。中断の理由は「管理画面から中断しました（実装エージェントの作業中）。」の形になる。
- 「テスト役の書きかけの変更は残していません。続けるときはテスト役が最初からやり直します。」→「テストエージェントの書きかけの変更は残していません。続けるときはテストエージェントが最初からやり直します。」

#### GitHub・Discord に書く文章とエラーの文言

次の文言の「～役」を 1. の表のとおりにする。文の他の部分は変えない。

- `src/implementer.ts`：異議のコメント（「実装役が受け入れテストの不備を指摘しました…テスト役に次の指摘を渡して…」）、異議の上限で Blocked にしたときの文、PR の本文（「conductor の実装役が実装しました」）、「実装役の異議が上限（…）を超えました」、「実装役が … を返しました」
- `src/tester.ts`：「…テスト役が受け入れテストを書けませんでした…」「テスト役が … を返しました」「テスト役が受け入れテストを正しく書けませんでした。」
- `src/reviewer.ts`：「レビュー役が、受け入れテストと受け入れ条件の食い違いを指摘しました。…」（2か所）
- `src/approval.ts`：「PR #… はレビュー役が承認しました。…」「…実装役に次の指摘を渡します。」
- `src/rejection.ts`：「…実装役に次の指摘を渡します。」
- `src/sync.ts`：「…指揮役が main を取り込みました。」「テスト役に戻します…」「実装役に直させます…」
- `src/decomposer.ts`：「分解役を … 回起動しても作業用 Issue に分けられなかったため…」「分解役の結果に誤りがあります…」

上に無くても、人に見せる文章（方針「エージェントの呼び名」の「人に見せる文章とは」）に「～役」があれば同じように直す。

#### README.md

README.md の「～役」「役」を 1. の表のとおりにする。ただし設定のキーや置き場所（`roles.<役>.allow`・`.conductor/<役>/*.md`）は書き方を変えない（方針「エージェントの呼び名」により判断）。

### 3. 変えないもの（方針「エージェントの呼び名」により判断）

- `claude -p` に渡すだけの文章：各役の決まり（`TESTER_RULES`・`IMPLEMENTER_RULES`・`REVIEWER_RULES`・`SPECIFIER_RULES`・`RESPEC_RULES`・`DECOMPOSER_RULES`）、レビューの観点の指示（`src/reviewer.ts` の「ほかの観点は別のレビュー役が確認します。」）、テスト役に渡す異議の前置き（`src/rejection.ts` の「実装役の指摘: 」）。
- コードの識別子、設定のキー（`roles`）、置き場所（`.conductor/<役>/`）、記録の `role` の値（`tester` など）。
- コードのコメント、`.conductor/` の指示ファイル、`package.json` の説明、Issue のテンプレート。
- 英語の文言。

### 4. テスト

今の文言を確かめているテストは、新しい文言に合わせて直す。少なくとも次がある。

- `src/loop.test.ts`（中断の理由）
- `src/acceptance/63-dashboard.test.ts`（動いている役の「実装役」）
- `src/acceptance/65-task-detail.test.ts`（経過の「テスト役」）
- `src/acceptance/68-settings.test.ts`（タブ名「役の許可」、見出し「実装役に変えさせないファイル」「役ごとの追加許可」「役ごとの指示ファイル」、役の名前の辞書）

`src/acceptance/` は保護対象なので、テストエージェントが直す。偽の役の名前（`fakeRole("仕様化役")` など）やテスト名・コメントは画面に出ないので直さなくてよい。

## 受け入れ条件

1. 管理画面（日本語）のダッシュボード・タスク詳細で、動いている役・経過の役が「テストエージェント」「実装エージェント」「レビューエージェント」「仕様化エージェント」「分解エージェント」と出る。「CI」「マージ」はそのまま。
2. 管理画面（日本語）の設定で、タブ名が「エージェントの許可」、見出しが「実装エージェントに変えさせないファイル」「エージェントごとの追加許可」「エージェントごとの指示ファイル」と出る。
3. 管理画面から中断すると、中断の理由が「管理画面から中断しました（実装エージェントの作業中）。」のように出る。中断のダイアログで役がわからないときは「動作中のエージェントを止め、…」と出る。
4. 実装エージェントが異議を返したときのコメント、レビューエージェントが承認して承認待ちにしたときのコメント、main を取り込んだときのコメントに「～役」が無く、「～エージェント」と書かれている。
5. `src/` と `web/src/` の、人に見せる文言（テストとコメント、`claude -p` に渡すだけの文章を除く）に「役」の字が残っていない。
6. 管理画面を英語にしたときの文言は今までどおり。
7. lint・整形・型・テスト・ビルドが通る。
